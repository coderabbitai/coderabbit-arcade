# Hoppy’s Adventure Arcade

A Godot 4.7.1 arcade collection with a reactive main menu and the first playable Platformer level, **Bay Area Blitz**. Runner, Beat’em Up, and the other platformer levels remain labeled placeholders.

Open `hoppys-adventure-arcade/project.godot` and press **F5**. Choose **Platformer Game → Level Select → Play Bay Area Blitz**.

Move with A/D or arrows, jump with Space, swipe with J/X, and pause with Escape. Controller movement, A/Cross jump, X/Square attack, and Start pause are also mapped.

See [Bay Area Blitz notes](docs/bay-area-blitz.md) for gameplay, tuning, implementation limits, and tests; see [main menu notes](docs/main-menu.md) for the arcade hub.
