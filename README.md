# Hoppy’s Adventure Arcade

A Godot 4.7.1 arcade collection. The current implementation is the main menu; gameplay modes have labeled placeholder screens.

Open `hoppys-adventure-arcade/project.godot` and press **F5** to play.

See [main menu notes](docs/main-menu.md) for controls, architecture, asset mapping, and smoke-test instructions.

Endless Runner frontend: [run, ownership, assets, and verification](docs/endless-runner.md).
