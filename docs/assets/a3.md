# A3 hazards and projectiles: creative pass C2 (Blender hero props)

Every barrier is now a scripted Blender hero prop (`tools/blender/props/build_props.py`, seed 52019) mounted by
`hazard_art.gd`. Mechanics are unchanged: hitboxes, dodge hints, spawn logic, labels, floor markers
(MARKER_Y 0.02, SafeGap 0.03), telegraph/laser-state hooks, pause freeze and the 110 % envelope. Boss projectiles
keep the procedural `_projectile()` rig as the fallback (C4 owns per-boss art).

| Kind | Prop | Idle motion |
|---|---|---|
| pr_backlog_low (JUMP) | jammed merge-queue conveyor, 11 stacked PR crates, striped gates with red beacons | crates shudder |
| pr_backlog_high (ROLL) | hanging review-scanner gantry: truss, red scanline fascia, underside sensor bar | two scan heads sweep, PR tickets swing |
| bug_swarm | three armoured beetles, DANGER elytra with glowing veins, jointed legs, red eyes | bodies bob, wings flutter |
| merge_conflict | split diff slab, jagged fracture; `<<<<<<<` ours (slate/DANGER), `>>>>>>>` theirs (the only LILAC) | halves grind |
| deprecated_pit full / two_lane | crumbling legacy-code rim at floor level (top <= 0.02 m), sagging lip chunks, broken red lip, struck-through @deprecated plaques, over the unchanged parallax well | none (well shader clock) |
| laser_grid ground/mid/high/timed | CI linter emitter pods (lens rows, fins, status bar); mid scales y by 0.75 | timed CHARGING ramps the pod emission |
| comment_flood | wall of 24 review-thread cards (avatar, code lines, red changes-requested tab) on thread spines | cards flutter |
| build_shockwave | cracked build-pipeline ring spanning all lanes, jagged glowing crest, red crack leaks | 14 debris shards bob and spin |

Runtime: the GLB's SceneState is read once at script load (`HazardArt.warm_props()`, ~3.5 ms) into per-root
layouts. GLB empties become pivots; each GLB mesh is remapped once into the unit box and batched per shared mesh
(normals/tangents pre-divided by the instance size, because MultiMesh instances transform them by the plain
basis; verified pixel-identical against a MeshInstance). One private `prop.gdshader` material per rig (clock,
hit, charge, distance uniforms) over one shared 1024 atlas set (albedo / normal / ORM / emission). No `TIME`,
no `instance uniform`, hit flash only brightens the baked emissive mask.

All within 14 draws and 6000 triangles (no raise to 9000 needed). Checks rewritten design-neutrally in
`tests/assets/a3_check.gd` (bug counts, shockwave arcs/shards, pit bottom and material-key pins replaced by:
baked-layout mounting, unit-box batching, DANGER hurt share >= 1 %, no MINT/MATRIX/ORANGE glow, LILAC only on
"theirs", CREAM code-line ink on crates/cards/tickets/ours, emissive <= 40 %, articulated beetles with thin
tapered clock-driven wings, one continuous low ring plus >= 8 debris, crumbling lip below the floor, shared
per-kind meshes, shared atlases). ASSET A3: PASS (93979 checks). Captures: `capture_a3.gd` 68/68 PASS,
`capture_gallery.gd` 19/19 (`a3-gallery-*.png`), Blender turntables `a3-blender-*.png`.

Determinism: geometry, node layout, triangle census and material recipes rebuild bit-identically; Blender's UV
unwrap/pack solvers are not bit-stable between identical runs (measured), so atlas bytes can differ per rebuild.
The checks pin properties, not bytes.
