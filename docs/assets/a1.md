## How to rebuild

Blender must run on the host; it crashes in the sandbox. From `hoppys-adventure-arcade/`, rebuild the GLB, render the front/three-quarter/rear turntables, then import into Godot:

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --python-exit-code 1 --python tools/blender/rebuild_hoppy.py -- --out Assets/runner/hoppy/hoppy.glb
/Applications/Blender.app/Contents/MacOS/Blender --background --python-exit-code 1 --python tools/blender/render_hoppy.py -- Assets/runner/hoppy/hoppy.glb /tmp/hoppy-turntables
/Applications/Godot.app/Contents/MacOS/Godot --headless --log-file /tmp/a1-import.log --path . --import
```

## Character and runtime

`tools/blender/build_hoppy.py` authors the original character, quad-ring subdivided limbs, blended joint weights, expressive face, bent ears, hoodie/hood/pocket/cuffs, embossed braces, piping, goggles, wrist screen, battery pack and sneakers. Body textures are 2048 square; accessory textures are 1024 square. `glb_atlas.py` shares eight atlas images/texture entries, including one ORM texture per atlas referenced by both occlusion and metallic/roughness. The accepted round-6 bake includes rounded soles, a deeper hood and corrected palette and brace marks.

`hoppy_runner_visual.tscn:3` instances the imported GLB under `Root/Model`. `hoppy_runner_visual.gd:34` uses the imported Skeleton3D and AnimationPlayer, duplicates clips/materials per instance, and restores the public AnimationPlayer path with the imported animation root preserved. Its thirteen actions are idle/run/fall loops, jump/roll/hurt/dead one-shots and the round-18 movement one-shots (lane_dash_left/right, land, shield_brace, powerup_react, victory). Cross-fades are 0.08 seconds, with zero blend entering the roll and 0.1 leaving it. jump/roll/dead hold their final pose until the backend requests another state; hurt and the round-18 one-shots return to the previous locomotion state. No backend behavior was changed.

`hoppy_runner_visual.gd:120` retains all six contract hooks. Normalized run speed is clamped to 0..1 and maps to 0.9..1.6 animation speed. Root Z lean remains -direction * 0.12. `hifi/lane_look.gd:1` applies a small head yaw after animation evaluation. Hit flashes tint private material copies instead of adding a full-character overlay pass. The retained hex shader drives shield/aura shells centered from the chest bone; their roll radius/center stay inside 0..0.9 m. MATRIX glyphs emit from the animated hood position at speed. All cosmetic nodes are PAUSABLE with interpolation OFF.

No external assets are downloaded. `Assets/runner/LICENSES.md` records original in-repo work under the project licence.

It suppresses only Blender 5.2's exact redundant sampler notice. The wrapper filter passed a plain-Python check. The coordinator completed the host rebuild; the shipped GLB, sidecar and recipe provenance checks pass in A1.
