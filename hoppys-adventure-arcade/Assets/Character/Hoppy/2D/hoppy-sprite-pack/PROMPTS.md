# Generation prompts

Created with the built-in image generation tool. Original generated images are retained in `sources/`; game atlases are mechanically sliced, repositioned onto fixed cells, and resized with nearest-neighbor sampling. Artwork was not repainted by code.

## Platformer

Use case: stylized-concept. Create a production sprite animation atlas for Hoppy in a retro 2D platformer, using the attached comic references for character identity only. Orange rabbit, cream muzzle and inner ears, large expressive dark eyes, dark charcoal short-sleeve shirt without lettering, cream tail, bare orange rabbit feet. Crisp charming 16-bit pixel art, limited palette, strong dark contour, consistent proportions. Transparent background with actual alpha, no grid lines, no text, no labels, no scenery, no shadow. EXACT regular 6 columns by 6 rows, square image 1536x1536, each cell 256x256. Every pose fully inside its cell with generous padding. Same scale throughout, standing character about 185 pixels tall including ears, feet baseline 228 in each cell, horizontal body center 128. All face right three-quarter side view. Each row is ONE coherent six-frame animation read left to right. Row 1 idle breathing with ear bounce. Row 2 running complete cycle, alternating legs and arms with distinct contact passing flight poses. Row 3 jump sequence anticipation crouch, takeoff, rising tucked legs, apex, falling, landing crouch. Row 4 melee paw swipe anticipation, windup, extension, strongest extension, followthrough, recovery. Row 5 hurt recoil six stages and recover. Row 6 defeat stumble, buckle, fall, lying down, lying down settle, final lying pose. Keep outfit head size and facial identity strictly consistent, animate real limbs not copies shifted in position. Align grounded poses by feet; jump poses retain sprite origin and can lift within cell. Pixel clusters, no painterly texture. References are inspiration; ignore all written comic dialogue.

## Brawler

Match orange rabbit identity, charcoal shirt without lettering, cream muzzle and tail, expressive eyes, dark contour and crisp limited palette pixel-art style of reference sprite atlas exactly. Actual transparent background, no labels no text no grid lines no shadows. EXACT SIX columns and SIX rows of evenly spaced animation frames, 1536x1536 square, 256x256 cells. Character full body stays within every cell with 20px margin. Feet grounded at local y=226, pelvis center x=110. Same proportions and scale across poses, tall ears must not clip. All facing right in 3/4 view except spinning poses. Six sequential frames per row. Row 1 combat idle guard, gentle breathing fists raised. Row 2 walking cycle forward, alternating legs clear contact pass contact pass, guard held. Row 3 jab: guard, fist windup, fast extension, full extension, retract, guard. Row 4 overhead swing: crouch windup, arms raised, overhead fist arc, strong downward hit, followthrough, recover. Row 5 spinning kick: crouch, twist back, spin side, fully extended horizontal kick right, follow through, return guard. Row 6 item pickup: upright, bend knees, crouch reaching ground, grasp with empty paw, rise, upright. No weapons no props. Real anatomy movement with consistent hands feet and clothing. No speed streaks outside cells. Pixel art game asset, not comic illustration. The attached comic is identity reference only, ignore its text.
